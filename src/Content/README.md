# Integração de conteúdo

`demo_content.gd` indica o manifesto em `assets/core/content.tres`, abre a biblioteca do LDK e mantém o banco publicado pela tela de inicialização. O mundo e suas interfaces compartilham o banco durante a sessão. O script também contém o mapa de migração dos índices da demo antiga.

`demo_content.gd` também publica os atalhos dos pacotes registrados para o serviço de preferências.
