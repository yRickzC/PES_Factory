# Itens nativos

Cada item tem um `.tres` com seu ID, nome e limite de pilha. Itens de construção apontam para o ID do bloco que posicionam. Ícones por ID são resolvidos no manifesto do pacote.

As flores amarela, rosa e lilás são itens empilháveis. Cada uma referencia por ID a entidade da mesma cor, que pode ser colhida e plantada de novo.

`pickaxe.tres` define a picareta, seu equipamento de mão com poses do balanço e a ação de mineração aplicada no impacto.

`sword.tres` define a espada de pedra `core:sword`. A ação corpo a corpo causa 3 de dano e configura alcance, arco, janela ativa, intervalo entre golpes e o preset de feedback do atacante. A aparência define a empunhadura, o rastro e a faísca de impacto.
