# Receitas nativas

Cada receita tem um `.tres` com categoria, ingredientes, produto, quantidades e tempo de fabricação. Os vínculos com itens e categorias usam IDs registrados.

`pickaxe.tres` fabrica uma picareta de pedra com duas tábuas e duas pedras.

`sword.tres` fabrica uma espada de pedra com uma tábua e duas pedras.
